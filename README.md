# 彤顏診所 Ton Yen｜年度營運儀表板 V01

沿用已定稿四頁私人儀表板架構，使用獨立資料來源與米色視覺。年度區間定義於來源 Sheet，程式與本文件不內建。

## 安全架構

- 公開儲存庫只放程式，不含 PDF、營運數字、目標值、存取權杖或密碼。
- Google 登入採 Sheets 唯讀授權；實際存取由來源 Sheet 共用權限決定。
- 來源 Sheet 僅以「指定人員」共用，不得使用「知道連結的人」。
- Google OAuth Client ID 不是密碼，不得加入 Client Secret。
- 「已授權的 JavaScript 來源」只登錄正式網域，避免他人複製程式後可登入。
- 資料只存在登入後的瀏覽器記憶體；登出、逾時或讀取失敗時清除，不使用持久化儲存。

## 結構與更新

- `dashboard.template.html`：固定米色四頁版型。
- `dashboard-data.js`：月份、分店、新舊客、Meta 與各平台年度預算驗證。
- `dashboard.js`：Google 登入、即時讀取、篩選及每 5 分鐘更新。
- `config.js`：來源 Sheet 識別碼與公開 OAuth client ID。
- `node build_v02.js`：檢查語法並產生 `index.html`，不可手改產生檔。
- `node --test dashboard.test.js`：只使用合成資料，不含真實營運數字。

## 計算規則

- 新客實績為依預約日期的新客到店數，不使用消費數或客服詢問數。
- 分店更名前後使用同一穩定分店代碼；來源名稱留在 Sheet 稽核欄。
- 各分店目標的起訖月份與數值一律由來源 Sheet 提供；確認沒有目標的月份記為 0，不視為缺漏。
- Meta 僅計平台「訊息對話開始次數」，CPA 為訊息花費除以 Meta 詢問數。
- 活動名稱無法明確歸店時保留「品牌整體」，不硬分攤。
- 未知預算與 LAP 實際花費保留空白，不當成 0。
- Meta 與年度預算的同月實際花費不一致時停止顯示。
- 年度預算固定包含 Meta、Google 關鍵字、Google 多媒體與 LAP 品牌私域；任何月份缺少平台時停止顯示。
- 本機 `file://` 不支援 Google 登入；正式版須使用已授權的 HTTPS 來源。

私人驗收、月報、日誌、目標值、Sheet 位址與範圍、帳號清單與數值匯出保存在本機或正式工作中樞，不加入 Git。
